# Requirements summary

- [Core and local service](../core.md) is partly built. It provides the shared Rust workspace and real loopback readiness endpoint. The parity map identifies the v1 sources and linked product work.
- [Web and Tauri host](../hosting.md) serves the built web client and catalog from one local HTTP origin. The desktop shell embeds the same host. Both clients can open review sources through the shared host.
- [Application settings](../settings.md) persist appearance, host-approved AI provider and model selection, and Code Guidance topics in the shared workbench.
- [Direct comparison](../direct-comparison.md) is partly built. The core compares file pairs and directory trees. The workbench opens file and folder pairs. Media presentation is tracked separately.
- [Comparison content](../comparison-content.md) is partly built. Shared hunks and original media inputs, including local Git LFS media, are implemented. The workbench has inline and split text viewers, raster and SVG views, and side-specific region feedback. [Diagram rendering](../content-plugins.md) is available through a configured subprocess for comparisons and thread attachments.
- [Review feedback](../feedback.md) has the shared thread, reply, attachment and anchor model. The disk bundle writer, editable snapshot storage, quoted instruction, Hot Sheet 2 delivery client, and manual storage operations are implemented. The inline discussion and contextual inspector support reviewer edits and publish the current feedback to disk. The Share menu copies the current bundle instruction, sends the complete bundle to a new or existing Hot Sheet 2 ticket, and opens saved reviews and stale discussions for the current comparison. The storage settings dialog reports usage and confirms project or global deletion of saved bundles. Legacy Glassbox v1 SARIF import was retired in HS2-NKX7N3.
- [Git review](../git-review.md) is partly built. The core retrieves Git change metadata and patches. The CLI starts a client through Git difftool, and the shared host exposes launch paths. The workbench opens Git reviews and difftool launches and lists changed files. The workbench restores changed-file visits and scroll position.
- [Source navigation](../symbol-navigation.md) resolves Rust, TypeScript, JavaScript, and Python definitions on the clicked Git side and opens revision-bound source links from AI notes. The workbench highlights matching diff lines or shows a read-only excerpt. Back and forward restore each view.
- [UI conventions](../../clients/web/docs/ui-conventions.md) are in use. The Kerf catalog ships grouped specimens for the review workbench and navigator. Source selection and the changed-file navigator are implemented. The text diff viewer ships with a catalog specimen. The review discussion catalog specimen includes reviewer and AI threads.
- [AI provider plugins](../ai-providers.md) provide a shared provider contract with a local HTTP adapter and an optional Apple Foundation Models adapter. The shared service exposes cancellable risk, narrative, and guided review jobs and publishes valid AI line notes. The workbench can choose a host-approved model and independently enable risk and guidance while showing the text diff. Cloud adapters and cross-platform release verification are tracked separately.
- [Glassbox v1 workflow parity](../v1-workflow-parity.md) records the remaining product decisions. Selected files expose path copying and desktop file actions. Symbol navigation has a focused follow-up.
- [Glassbox v1 carry-forward audit](../v1-gap-audit.md) records the broader review of v1 features and safeguards. Its decision register awaits maintainer sign-off.
- PostgreSQL, the review completion lifecycle and ground-truth image comparison are retired. Native clients and distribution decisions are deferred.
