# Requirements summary

- [Core and local service](../core.md) is partly built. It provides the shared Rust workspace and real loopback readiness endpoint. The parity map identifies the v1 sources and linked product work.
- [Web and Tauri host](../hosting.md) serves the built web client and catalog from one local HTTP origin. The desktop shell embeds the same host. Both clients can open review sources through the shared host.
- [Application settings](../settings.md) persist appearance, host-approved AI provider and model selection, and Code Guidance topics in the shared workbench.
- [Direct comparison](../direct-comparison.md) is partly built. The core compares file pairs and directory trees. The workbench opens file and folder pairs. Media presentation is tracked separately.
- [Comparison content](../comparison-content.md) is partly built. Shared hunks and original media inputs, including local Git LFS media, are implemented. The workbench has inline and split text viewers with controls that reveal unchanged lines around each change (`HS2-DZ8ZR6`) and a Find field that highlights and steps through matches in the lines shown (`HS2-30ZEFE`), raster and SVG views with synchronized pan, gesture zoom and a Focus view for one side (`HS2-XJWGYD`), and side-specific region feedback that can be redrawn by keyboard or pointer and anchored to a whole image (`HS2-9MZ32M`). [Diagram rendering](../content-plugins.md) is available through a configured subprocess for comparisons and thread attachments, and a Diagram Renderers dialog reports readiness and what a missing tool needs (`HS2-Q9TXER`).
- [Review feedback](../feedback.md) has the shared thread, reply, attachment and anchor model. The disk bundle writer, editable snapshot storage, quoted instruction, Hot Sheet 2 delivery client, and manual storage operations are implemented. The inline discussion and contextual inspector support reviewer edits, moving a line thread to another line or side (`HS2-TGAGQ4`), suggesting a new line for a stale comment when its text has one shown match (`HS2-RV5BD8`), and publish the current feedback to disk. A dependency advisory gate audits the web npm lockfile and both Rust lockfiles in CI, with dated exceptions only (`HS2-0N4NPR`, [dependency audit](../dependency-audit.md)). An AI note can cite a commit, and following the citation opens that commit at the cited line in a new tab while the original review stays as it was (`HS2-B5K6GM`). Attachments preview as thumbnails or PDFs only when the host verifies their type, and a verified one can be opened externally on request (`HS2-3G613V`). The Share menu copies the current bundle instruction, sends the complete bundle to a new or existing Hot Sheet 2 ticket, and opens saved reviews and stale discussions for the current comparison, and deletes one saved review after confirmation (HS2-42A696). The storage settings dialog reports usage and confirms project or global deletion of saved bundles. Legacy Glassbox v1 SARIF import was retired in HS2-NKX7N3.
- [Feedback JSON export](../feedback-export.md) is shipped: every bundle publishes a versioned `feedback.json` beside `review.md`, with a golden fixture, a consumer test across every feedback type and a real-host test (`HS2-A07MHD`).
- [Git review](../git-review.md) is partly built. The core retrieves Git change metadata and patches. The CLI starts a client through Git difftool, registers or unregisters Glassbox as the default Git difftool in a named scope (`HS2-HVP8Q1`) and groups the per-file launches of one plain `git difftool` run into one review (`GB2-FXJSSM`), and the shared host exposes launch paths. The workbench opens Git reviews and difftool launches and lists changed files. The workbench restores changed-file visits and scroll position. A Symbol Outline dialog lists a file's declarations on the Before or After side and jumps to one (`HS2-E3YMJ5`, documented in `docs/symbol-navigation.md`). The changed-file list can be ordered by risk or by the narrative analysis without hiding any file (`HS2-5P1B23`). Reviewers can mark files reviewed and see per-comparison progress that drops a mark when the file changes (`HS2-FTEQVQ`).
- [Source navigation](../symbol-navigation.md) resolves Rust, TypeScript, JavaScript, and Python definitions on the clicked Git side and opens revision-bound source links from AI notes. The workbench highlights matching diff lines or shows a read-only excerpt. Back and forward restore each view.
- The [Git source form](../git-review.md) keeps a missing repository path editable and asks the reviewer to check it and try again (`GB2-W65NZN`).
- [UI conventions](../../clients/web/docs/ui-conventions.md) are in use. The Kerf catalog ships grouped specimens for the review workbench and navigator. Source selection and the changed-file navigator are implemented. The text diff viewer ships with a catalog specimen. The review discussion catalog specimen includes reviewer and AI threads.
- [AI provider plugins](../ai-providers.md) provide a shared provider contract with a local HTTP adapter and an optional Apple Foundation Models adapter. The shared service exposes cancellable risk, narrative, and guided review jobs and publishes valid AI line notes. The workbench can choose a host-approved model and independently enable risk and guidance while showing the text diff. Cloud adapters and cross-platform release verification are tracked separately.
- [Glassbox v1 workflow parity](../v1-workflow-parity.md) records the remaining product decisions. Selected files expose path copying and desktop file actions. Symbol navigation has a focused follow-up.
- [Glassbox v1 carry-forward audit](../v1-gap-audit.md) records the maintainer's sign-off on 20 decisions that have shipped and seven that are out of scope. The [macOS and Linux verification record](../release-verification.md) tracks automated coverage and the remaining real-app and installed-package checks.
- PostgreSQL, the review completion lifecycle and ground-truth image comparison are retired. Native clients and distribution decisions are deferred.
- [Deterministic demo capture](../demo-capture.md) is shipped as a harness (`HS2-5HS40W`): shared scene definitions, named ready states, and a byte-for-byte determinism check over PNG and SVG output. The public showcase and the comparison suite build on it and are not built yet.
