# Requirements summary

- [Core and local service](../core.md) is partly built. It provides the shared Rust workspace and real loopback readiness endpoint. The parity map identifies the v1 sources and linked product work.
- [Web and Tauri host](../hosting.md) serves the built web client and catalog from one local HTTP origin. The desktop shell embeds the same host. Both clients can open review sources through the shared host.
- [Application settings](../settings.md) persist appearance, host-approved AI provider and model selection, and Code Guidance topics in the shared workbench.
- [Direct comparison](../direct-comparison.md) is partly built. The core compares file pairs and directory trees. The workbench opens file and folder pairs. Media presentation is tracked separately.
- [Comparison content](../comparison-content.md) is partly built. Shared hunks and original media inputs, including local Git LFS media, are implemented. The workbench has inline and split text viewers with controls that reveal unchanged lines around each change (`HS2-DZ8ZR6`) and a Find field that highlights and steps through matches in the lines shown (`HS2-30ZEFE`), raster and SVG views, and side-specific region feedback. [Diagram rendering](../content-plugins.md) is available through a configured subprocess for comparisons and thread attachments.
- [Review feedback](../feedback.md) has the shared thread, reply, attachment and anchor model. The disk bundle writer, editable snapshot storage, quoted instruction, Hot Sheet 2 delivery client, and manual storage operations are implemented. The inline discussion and contextual inspector support reviewer edits, moving a line thread to another line or side (`HS2-TGAGQ4`), suggesting a new line for a stale comment when its text has one shown match (`HS2-RV5BD8`), and publish the current feedback to disk. The Share menu copies the current bundle instruction, sends the complete bundle to a new or existing Hot Sheet 2 ticket, and opens saved reviews and stale discussions for the current comparison, and deletes one saved review after confirmation (HS2-42A696). The storage settings dialog reports usage and confirms project or global deletion of saved bundles. Legacy Glassbox v1 SARIF import was retired in HS2-NKX7N3.
- [Feedback JSON export](../feedback-export.md) is shipped: every bundle publishes a versioned `feedback.json` beside `review.md`, with a golden fixture, a consumer test across every feedback type and a real-host test (`HS2-A07MHD`).
- [Git review](../git-review.md) is partly built. The core retrieves Git change metadata and patches. The CLI starts a client through Git difftool, registers or unregisters Glassbox as the default Git difftool in a named scope (`HS2-HVP8Q1`), and the shared host exposes launch paths. The workbench opens Git reviews and difftool launches and lists changed files. The workbench restores changed-file visits and scroll position. Reviewers can mark files reviewed and see per-comparison progress that drops a mark when the file changes (`HS2-FTEQVQ`).
- [Source navigation](../symbol-navigation.md) resolves Rust, TypeScript, JavaScript, and Python definitions on the clicked Git side and opens revision-bound source links from AI notes. The workbench highlights matching diff lines or shows a read-only excerpt. Back and forward restore each view.
- [UI conventions](../../clients/web/docs/ui-conventions.md) are in use. The Kerf catalog ships grouped specimens for the review workbench and navigator. Source selection and the changed-file navigator are implemented. The text diff viewer ships with a catalog specimen. The review discussion catalog specimen includes reviewer and AI threads.
- [AI provider plugins](../ai-providers.md) provide a shared provider contract with a local HTTP adapter and an optional Apple Foundation Models adapter. The shared service exposes cancellable risk, narrative, and guided review jobs and publishes valid AI line notes. The workbench can choose a host-approved model and independently enable risk and guidance while showing the text diff. Cloud adapters and cross-platform release verification are tracked separately.
- [Glassbox v1 workflow parity](../v1-workflow-parity.md) records the remaining product decisions. Selected files expose path copying and desktop file actions. Symbol navigation has a focused follow-up.
- PostgreSQL, the review completion lifecycle and ground-truth image comparison are retired. Native clients and distribution decisions are deferred.
