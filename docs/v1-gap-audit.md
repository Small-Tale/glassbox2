# Glassbox v1 carry-forward audit

HS2-Z0DANP reviews the v1 feature set against the Glassbox 2 requirements and implementation at `8f2b44d7edd0c70162a6472c106860fcf866441a`. Glassbox 2 ships independently, with its own package and data. The [prior parity decisions](v1-workflow-parity.md) still apply. The register below records the proposals and the [sign-off](#sign-off).

## Sources and scope

The v1 snapshot is [`e6a418288144cf0b73511c2279c4d03036f3442c`][v1]. The audit checked all 34 numbered feature documents, the [architecture][architecture] and [manual test plan][manual], and screened all 541 reachable commit subjects for platform, installation, security and data-integrity fixes. The [GitHub issue list][issues] returned two issues across all states, both closed. v1 maintainers reported fixes in 1.2.2 for [#57][issue-57] and in 1.2.3 for [#59][issue-59]. The v2 findings are based on repository requirements, source and existing tests. Installed Windows verification is deferred.

## Maintainer decision register

**Keep** recommends carrying forward the user-visible outcome. **Rework** recommends a narrower version that fits v2. **Drop** recommends leaving the v1 capability out. Mark each ID **In** or **Out**. Each accepted ID gets a focused ticket with the agreed scope.

| ID  | Undecided v1 behavior                                                                                                                            | Recommendation                                                                                                                                                |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D01 | Resume the latest review from the launch command, including after HEAD changes ([1][v1-1], [2][v1-2]).                                           | **Drop.** V2 already reopens saved discussions from the selected comparison, with explicit stale-revision handling.                                           |
| D02 | Browse reviews across a repository, including comparisons outside the current source ([1][v1-1], [18][v1-18]).                                   | **Rework.** Add a read-only index over editable bundles with source identity and last edit time.                                                              |
| D03 | Delete a specific saved review from history ([1][v1-1]).                                                                                         | **Keep.** Add confirmed single-bundle deletion to Saved Reviews, including active-writer protection. Project and whole-store cleanup already exist.           |
| D04 | Launch a chosen Git mode or direct path pair from a general-purpose CLI ([2][v1-2], [18][v1-18]).                                                | **Rework.** Support explicit Git and direct inputs on the chosen launch path.                                                                                 |
| D05 | Register or unregister Glassbox as the default Git difftool from Settings or the CLI ([2][v1-2], [19][v1-19]).                                   | **Drop.** The scoped wrapper and documented Git config already cover both opt-in use cases.                                                                   |
| D06 | Accumulate all ordinary per-file Git difftool invocations into one live window ([19][v1-19]).                                                    | **Drop.** Directory difftool already groups files, and the foreground model preserves temporary paths.                                                        |
| D07 | Expand unchanged text around a hunk and toward file edges on demand ([4][v1-4], [18][v1-18], [32][v1-32]).                                       | **Keep.** Fetch bounded context from the selected revision and render any current v2 discussion anchors in the newly exposed lines.                           |

| D10 | Drag a line annotation to another line or side ([5][v1-5]).                                                                                      | **Rework.** Offer an explicit move or rebind action with keyboard access and revision checks.                                                                 |

| D17 | Synchronize image gestures across both panes and open an image side full screen ([24][v1-24], [28][v1-28]).                                      | **Rework.** Build on shared zoom and scrolling. Reuse the same region coordinates in a focused view.                                                          |
